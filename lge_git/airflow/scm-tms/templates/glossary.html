페이지 구성

대시보드를 구성하는 화면/메뉴 설명

용어설명
Order Analysis주문 분석 페이지. 과거 주문 데이터를 다양한 관점(법인, 기간, 카테고리 등)에서 분석하는 화면입니다.
Active Orders활성 주문 대시보드. 현재 처리 중인(Open) 주문의 진행 상황과 위험도를 실시간으로 모니터링하는 화면입니다.
Legal Entity법인. LG전자의 해외 현지법인 코드입니다. (예: LGEAP = 호주/뉴질랜드, LGEDG = 독일/스위스)대시보드 우측 상단에서 법인을 선택하면 해당 법인의 데이터만 필터링됩니다.

시스템 약어

각 처리 단계를 관할하는 시스템

용어설명
GERPGlobal ERP LG전자 글로벌 전사자원관리 시스템. 주문 입력(Entered)부터 피킹 출고(Pick Release)까지의 주문 단계(Order Stage)를 관리합니다.
TMSTransportation Management System 운송 관리 시스템. 적재 생성(Load Creation)과 창고 출고(WH Release) 등 물류 배차를 관리합니다.
WMSWarehouse Management System 창고 관리 시스템. 출하 확인(Ship Confirm)부터 실제 출하(Shipped)까지 창고 내 물류 처리를 관리합니다.

주문 흐름 단계 (Flow Stage)

Order Stage (GERP) Shipping Stage (TMS / WMS)

단계설명
Order Stage GERP 관할
Entered / Booked주문 입력 / 확정 고객 주문이 시스템에 입력(Entered)되고 재고 확인 후 확정(Booked)된 상태입니다.
Hold보류 특정 사유(재고 부족, 신용 문제, 미래 출하 등)로 인해 주문 처리가 일시적으로 중단된 상태입니다.
Pick Ready피킹 준비 완료 보류 해제 후 창고에서 상품을 꺼낼(피킹) 준비가 된 상태입니다.
Pick Release피킹 출고 지시 창고에 상품 피킹(집품)을 지시한 상태입니다. 이후 물류 시스템(TMS)으로 넘어갑니다.
Shipping Stage TMS / WMS 관할
Load Creation적재 생성 TMS에서 배송 차량에 대한 적재 계획을 생성한 상태입니다.
Release To WH WH Release창고 출고 지시 TMS가 창고(Warehouse)에 출고를 지시한 상태입니다.
Ship Confirm출하 확인 WMS에서 상품이 실제로 창고를 떠났음을 확인한 상태입니다.
Shipped출하 완료 상품이 고객에게 배송 중인 최종 단계입니다.

진행 상태 (Progress Status)

RAD 기준 납기 위험도 분류

상태설명
On-track정상 진행 고객 요청 도착일(RAD)까지 충분한 여유가 있어 정상적으로 배송 완료가 예상되는 주문입니다.
At-risk위험 예상 현재 진행 속도로는 고객 요청일(RAD)을 맞추기 어려울 수 있는 주문입니다. 선제적 조치가 필요합니다.
Breached기한 초과 이미 고객 요청일(RAD)을 넘긴 주문이거나, 납기를 맞출 수 없는 것이 확실한 주문입니다.

Hold 유형 (Hold Breakdown)

보류 원인 분류 Back Order / Finance Hold / Future / Etc

유형설명
Back Order백오더 (재고 부족 보류) 주문 수량에 비해 현재 재고가 부족하여 출고가 보류된 상태입니다. 재고가 확보되면 자동으로 해제됩니다.
Finance Hold Credit + Overdue재무 보류 고객의 신용 한도 초과(Credit Hold) 또는 연체(Overdue Hold)로 인해 출고가 보류된 상태입니다. 재무팀 승인이 필요합니다.
Future미래 출하 보류 고객이 요청한 출하일이 아직 도래하지 않아 보류된 상태입니다. 요청일이 되면 자동 해제됩니다.
Etc기타 보류 위 유형에 해당하지 않는 기타 사유(수출 규제, 특별 승인 대기 등)로 보류된 주문입니다.

핵심 지표 (Key Metrics)

납기 관리에 활용되는 주요 측정 지표

지표설명
RAD Request Arrival Date고객 요청 도착일 고객이 요청한 상품 도착 희망일입니다. On-track / At-risk / Breached 상태의 기준이 됩니다.그리드에서는 "Customer RAD" 컬럼으로 표시됩니다.
IOD Ideal Order Delivery이상적 배송 완료 예상일 현재 단계에서 남은 처리 시간을 추정하여 계산한 예상 배송 완료일입니다."Est. 29.2d to IOD" = 배송 완료까지 약 29.2일 소요 예상
Est. miss RADRAD 미준수 예상 건수 해당 단계의 주문 중 고객 요청일(RAD)을 넘길 것으로 예상되는 주문 건수와 비율입니다."Est. miss RAD: 1,239 (69%)" = 전체 중 1,239건(69%)이 RAD 초과 예상
Est. Arrival예상 도착일 현재 진행 속도를 기반으로 추정한 고객 도착 예상일입니다.
Margin (d)여유 일수 고객 요청일(RAD)과 예상 도착일 사이의 차이(일)입니다.양수(+) = 여유 있음  |  음수() = 지연 예상
Avg d in stage단계 평균 체류 일수 해당 단계에 머무르고 있는 주문들의 평균 체류 기간(일)입니다. 숫자가 클수록 병목이 발생하고 있음을 의미합니다.
