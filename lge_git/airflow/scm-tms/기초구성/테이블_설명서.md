# SCM-TMS 테이블 설명서

> 6개 SQL 파일(`Appointment.sql`, `IOD&POD.sql`, `Load Build.sql`, `Load Release.sql`, `Load Tender.sql`, `Shipment.sql`) 에서 사용하는 테이블 정리

---

## 1. 핵심 운송/배송 테이블

| 테이블명 | 스키마 | 설명 | 사용 SQL |
|---|---|---|---|
| `LD_LEG_DETL_T` | TMSPROD | 운송 Leg(구간) 상세 테이블. Shipment를 출발지→경유지→도착지 단위로 분해한 핵심 기준 테이블 | 전체 공통 |
