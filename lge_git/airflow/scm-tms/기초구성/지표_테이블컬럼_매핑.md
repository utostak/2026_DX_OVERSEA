> 기준: `지표.csv` × SQL 쿼리 분석 (`Appointment.sql`, `Shipment.sql`, `Load Release.sql`, `Load Tender.sql`, `IOD&POD.sql`)

## 📌 범례

| 기호 | 의미 |
|---|---|
| ✅ | TMS 쿼리에서 컬럼 확인됨 |

## 1. 출하/배송 관리 영역

### 1-1. OTSP — 정시 운송계획 처리율
> **(정시 운송계획처리율)** 운송계획 기준일자에 운송계획 된 Shipment 건수  
> 지원 시스템: **TMS**

| 필요 데이터 | 테이블 | 컬럼 | 비고 |
|---|---|---|---|
| 운송계획 Due Date | `TB_GTM_DUE_DATE_CALC` | `LOAD_CREATE_DUE` | LC_BY ✅ |
| 운송계획 일자 (Load 생성일) | `TMSPROD.LD_LEG_T` | `CRTD_DTT` | Load Create Date ✅ |
| Shipment 번호 | `TB_GTM_SHIPMENT_TMS_S_IF` | `SHIPMENTNUMBER` | 건수 집계 기준 ✅ |
| Order Date | `TB_GTM_SHIPMENT_TMS_S_IF` | `SALES_ORDER_DATE` | ✅ |
| Req. Arrival Date | `TB_GTM_SHIPMENT_TMS_S_IF` | `ORI_DELY_TO` | RAD_DTTM ✅ |
| 출고 기준일 | `TB_GTM_SHIPMENT_TMS_S_IF` | `PICK_RELEASE_DATE` | 필터 기준 ✅ |
| Load 상태 | `TMSPROD.LD_LEG_T` | `CUR_OPTLSTAT_ID` | 계획 완료 여부 판단 ✅ |
| 법인 | `TB_GTM_LOAD` | `LEGAL_ENTITY_NAME` | 필터 ✅ |
